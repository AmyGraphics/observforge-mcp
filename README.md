# ObservForge MCP Server 👁️📡🚨

Universal Autonomous Observability, Error Tracking, Structured Logging, SLO Alerting & Incident Response Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_observability_architect`):** Ingests your stack and scale to synthesize a complete production observability plan in one call: per-pillar tool selection matrix (Sentry vs OpenTelemetry vs Grafana vs Axiom free tiers), instrumentation plan, sampling & retention policy, error budget policy, and a step-by-step deployment guide.
- 🚨 **Sentry Error Tracking Instrumentation (`instrument_error_tracking_sentry`):** Generates production-ready SDK init with source map upload, release tagging, PII redaction beforeSend hooks, React ErrorBoundary wiring, and anti-noise alert routing rules.
- 📝 **Structured Logging Layer (`structure_application_logging`):** Pino/Winston/Workers JSON logging with request correlation IDs, X-Request-ID propagation across services, PII redaction lists, and a machine-greppable canonical log schema.
- 📊 **SLO Dashboards & Burn-Rate Alerts (`build_slo_dashboards_and_alerts`):** Google SRE multi-window burn-rate alert rules (14.4x fast burn pages, 3x slow burn tickets), importable Grafana dashboard JSON, and a public status page component.
- 🕵️ **Blameless Incident Postmortems (`run_incident_postmortem_analysis`):** Turns raw error clusters and incident timelines into root-cause chain analysis, detection gap review, and prioritized P0/P1/P2 action items with owners.
